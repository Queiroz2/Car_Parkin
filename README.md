## 💡 Sobre o Projeto

O **Estacionamento Docente** nasceu da necessidade de resolver problemas de desorganização e falta de controle nas vagas destinadas aos professores da faculdade. A aplicação oferece uma interface simples e direta para acompanhar a ocupação do estacionamento em tempo real, evitando transtornos nos horários de pico das aulas.

*(Dica: Tire um print da tela principal do seu sistema, salve na pasta do projeto e coloque aqui usando `![Tela do Sistema](caminho-da-imagem.png)`)*

## ⚙️ Funcionalidades

- [x] **Controle de Vagas.** Visualização rápida de vagas disponíveis e ocupadas.
- [x] **Registro de Veículos.** Cadastro e remoção de entradas e saídas de professores.
- [x] **Armazenamento Local.** Os dados ficam salvos diretamente no navegador através do *LocalStorage*, mantendo as informações registradas mesmo após atualizar a página.

## 🛠 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web puras (*Vanilla*), sem necessidade de frameworks externos ou servidores de banco de dados:

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização e layout responsivo.
* **JavaScript:** Lógica de controle de vagas e manipulação de dados.
* **Web Storage API (LocalStorage):** Persistência dos dados diretamente no navegador do usuário.

## 🚀 Como Executar

Por ser uma aplicação front-end estática, não é necessário instalar dependências ou configurar bancos de dados. Siga os passos abaixo:

1. **Baixe o projeto:**
   * Clique no botão **Code** > **Download ZIP** aqui no GitHub e extraia a pasta, **ou** clone via terminal:
   ```bash
   git clone https://github.com
   ```

2. **Abra no VS Code:**
   * Abra a pasta do projeto no Visual Studio Code.

3. **Inicie com o Live Server:**
   * Certifique-se de ter a extensão **Live Server** instalada no VS Code.
   * Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server** (ou clique em *Go Live* no canto inferior direito).
   * O sistema abrirá automaticamente no seu navegador padrão.
